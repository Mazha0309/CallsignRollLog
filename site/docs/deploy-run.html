直接运行

用于在本机前台运行，或修改服务端代码。关闭终端或按 Ctrl+C 后进程停止。需要持续运行时，使用Docker Compose 一键或原生 Node.js 一键。

启动

在仓库目录，先按开始之前写好 .env。需要 Node.js 24.18+ 和 npm 10+。

npm ci
(cd web && npm ci)
(cd live && npm ci)
npm start

npm start 在前台运行。本机打开 http://127.0.0.1:3000，并用 curl -fsS http://127.0.0.1:3000/api/v1/server-info 确认。空库接着做第一个管理员。

开发运行

开发时用 npm run dev，改完会重新加载。这不是对外提供服务的运行方式。

提交前的完整检查是 npm run verify。它时间很长，而且不使用仓库里的生产数据库。不要为了运行检查而指向正在提供服务的 data/openlogtool.db。

无法完成

  • 启动后立即退出并报告密钥错误：.env 缺了四把之一，或 JWT_SECRET 仍是示例默认值。回到开始之前。
  • web 或 live 没装依赖：把上面的两个 npm ci 补上。只在仓库根目录 npm ci 不够。
  • 端口被占用：改 .env 里的 PORT，再启动。检查用的 URL 也要改成那个端口。
