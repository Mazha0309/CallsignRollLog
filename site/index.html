01

记录

点名时逐条录入。

字段
主控、来台呼号、时间、RST 发 / 收、QTH、设备、功率、天线、高度、备注。
补全
呼号、设备、天线、QTH 四类词典即时补全，输入新内容自动沉淀进词库。
操作
呼号自动大写、主控呼号保留上一台；Ctrl＋Enter 提交，可撤销上一条。
导出
JSON 与带样式的 Excel：标题居中加粗、表头配色、列宽行高自动适配。
可选 AI
语音识别与文字助手相互独立、默认关闭；密钥写入系统安全存储。
02

协作

连接自建服务器后启用。

加入
所有者把会话发布到服务器，他人凭 10 位邀请码加入同一份记录。
实时
连续事件补拉 + 鉴权 WebSocket；断线或请求丢失后复用同一 mutationId 恢复。
冲突
无重叠修改自动三方 rebase；同字段冲突进入冲突中心，由使用者决定取舍。
云同步
个人会话与词库多设备自动合并；个人记录不写入协作会话。
主控屏
独立窗口显示当前点名进度，桌面端以独立进程运行，显示窗口出错不会带崩主控台。
Live Share
为主控、远程书记员或观众生成只读公开网页，无需登录即可查看当前点名进度；链接可设 1 小时至 7 天自动失效，密钥仅在创建时显示一次。
角色权限
OWNER创建/撤销邀请、调整或移除成员、转移所有权、重命名与关闭会话
EDITOR新增、修改、删除记录
VIEWER只读；被撤权或会话关闭后强制只读

04

构建

Flutter 3.44+ · Dart 3.12+ · Rust 1.91.1

  1. 克隆仓库并执行 flutter pub get
  2. 按平台构建：flutter build linux|windows|macos，桌面与 Android 会一并编译 Rust 动态库
  3. 网页版另跑 bash tool/build_web.sh
  4. 需要协作时再部署 CallsignRollLogServer
bash
git clone https://github.com/Mazha0309/CallsignRollLog.git
cd CallsignRollLog
flutter pub get

# 桌面端（在各自系统执行）
flutter build linux      # 或 windows / macos

# Android
flutter build apk --release --split-per-abi

# 网页版
bash tool/build_web.sh
# 产物在 build/ 下
