# 扫码加入服务器

> 状态：待实施
> 日期：2026-10-16
> 仓库：`openlogtool`
> 不改服务端二维码内容

## 1. 这是干什么的

现在「扫一扫」只把二维码里的地址填进输入框，还要再点一次「确认地址并连接」。扫码页也没有手电筒、切换摄像头和从图片识别。Linux 与 Windows 不显示扫码按钮，因为当前相机插件不支持这两个系统。

改完之后，识别出有效地址就弹出一个确认框。确认后才连接；取消则不改当前服务器。手机、macOS 和网页继续用相机，并可以改用图片。Linux 与 Windows 用图片识别完成同一条确认后连接的路径。

## 2. 已经定下来的规则

1. **先确认，再连接。** 相机或图片得到有效地址后，只弹一个确认框。确认才调用现有的 `saveAndCheckServerUrl`。这只检查服务器，不登录，不发送账号或密码。
2. **取消不改任何东西。** 不改输入框里已有的地址，不切换服务器，不退出登录。相机确认框取消后，相机继续扫。
3. **换服务器的警告放在这一个框里。** 当前已登录，且识别出的地址和当前服务器不同时，框内同时说明：将连接到该地址、当前账号会退出、原登录凭据不会发到新地址、本机记录保留。不再接着弹出现有的「切换服务器？」对话框。
4. **同一台服务器也要确认。** 文案说明将重新检查这个地址。确认后仍执行一次服务器检查。
5. **未登录时只核对地址。** 不提退出账号。
6. **地址用现有规则整理。** 继续用 `validatedServerConnectionInput`。`/connect`、`/client/`、`/app`、`/admin` 会去掉；带账号密码、非 http(s)、空主机的内容视为无效。
7. **无效结果不连接。** 相机扫到无效码时留在扫码页并提示，相机不关。随后扫到有效码时先去掉这条提示，再弹确认框。图片无效时提示，不弹确认框。用户关掉文件选择器则什么都不做。
8. **粘贴保持原样。** 「粘贴连接地址」仍然只填入输入框，不弹这个确认框，也不直接连接。
9. **服务端二维码不改。** 「连接这台服务器」页面仍编码浏览器当前的 `/connect` 地址。

## 3. 明确不做

- 不自动登录。
- 不改服务端二维码、不改公开地址的生成方式。
- 不给 Linux 或 Windows 另接一套摄像头插件。
- 不把粘贴、手输也改成扫码这条确认框。手输后仍用现有的「确认地址并连接」，其中已有的切换服务器确认保持不变。
- 确认框不显示二维码原文里的查询参数、片段或用户信息。

## 4. 谁能用相机，谁用图片

| 平台 | 设置里的入口 | 相机 | 手电筒 | 切换摄像头 | 从图片识别 |
| --- | --- | --- | --- | --- | --- |
| Android、iOS | 扫一扫 | 有 | 控制器报告可用才显示 | 控制器报告有另一颗摄像头才显示 | 扫码页内 |
| macOS、网页 | 扫一扫 | 有 | 同上 | 同上 | 扫码页内 |
| Linux、Windows | 识别二维码图片 | 无 | 无 | 无 | 这就是入口 |

不支持的按钮不占位，也不在点击后报错。手电筒或切换摄像头调用失败时，按钮隐藏，扫码页保持可用。

图片选择用现有的 `file_picker`。解码吃图片字节，不依赖文件路径，这样网页和测试都能用。解码器是纯 Dart，不走 `mobile_scanner` 的 `analyzeImage`（网页不支持，Linux 与 Windows 没有该插件）。

## 5. 确认框文案

框标题是「连接到这台服务器？」。正文始终包含整理后的地址。

- 未登录，或已登录且地址相同：说明确认后将检查这台服务器，不会登录，也不会上传相机画面或图片。
- 已登录且地址不同：使用第 2 节第 3 条的切换说明，并带上整理后的地址。

按钮是现有的取消和确认。确认后关闭扫码页（图片入口没有扫码页），把整理后的地址写入服务器地址框，再连接。连接成功或失败都用现在的提示。失败时地址留在输入框里，方便改正后重试。

## 6. 文案与测试

新增和扫码页上现有的硬编码中英文都放进四份 ARB：`app_zh.arb`、`app_zh_CN.arb`、`app_en.arb`、`app_en_US.arb`，然后 `flutter gen-l10n`。

测试要锁住这些行为：

- 一张包含 `https://server.example/connect` 的二维码图片，解码并整理后是 `https://server.example`。损坏或没有二维码的图片得到空结果。
- 确认框文案选择：未登录、已登录且同一地址、已登录且不同地址，三种互不混用。
- 取消不调用 `saveAndCheckServerUrl`。
- 确认调用它，参数是整理后的地址；已登录且地址不同时，不会再出现第二个切换对话框。
- Linux 与 Windows 的入口不创建相机控制器。
