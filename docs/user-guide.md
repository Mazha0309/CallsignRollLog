# Callsign Roll Log 使用手册

这份手册给记点名的人。同一份内容发布在 <https://crl.mazha0309.com/docs.html>。怎么编译、协议字段和内部设计不在这里；那些分别见 [开发指南](development.md) 和服务器仓库的 API 文档。

Callsign Roll Log 是业余无线电点名记录工具，不是个人通联日志的替代品。本地使用不需要服务器，也不需要注册账号。

## 先分清几件事

下面这些名字容易混在一起。它们互相独立，开一个不会自动打开另一个。

| 你想做的事 | 用哪个 | 对方能看到什么 |
| --- | --- | --- |
| 自己记、自己导出 | 不登录，直接新建会话 | 只有这台设备 |
| 自己的记录换一台设备接着用 | 个人云同步 | 只有你自己的账号 |
| 几个人同时记同一场 | 好友与协作 | 这场的成员，按邀请时的权限 |
| 把自己已经记过的会话给另一个账号看或改 | 账号会话共享 | 你指定的那一个账号，范围由授权决定 |
| 让别人看进行中的公开页面 | 公开 Live Share | 拿到链接的人，只读、字段有裁剪 |
| 把已结束的记录做成静态归档 | 公开归档 | 打开归档页的人，不是实时的 |

结束本地记录不会自动公开。加好友也不会把自己的历史和个人云交出去。删好友不会把已经加入的协作成员踢出去。

## 界面

左侧（窄屏上是底部或抽屉）有四个入口：

- **点名台**：填当前这一条，并看记录表。
- **会话**：新建、继续、结束，以及可选的好友与协作。
- **数据**：导入导出、词库、本机数据库。
- **设置**：外观、工作台、主控屏、AI、服务器与账户、应用。

没有会话时，点名台会提示先去新建会话或加入协作。

## 记一条

点名台的表单包括主控呼号、点名呼号、设备、天线、功率、QTH、高度、时间、信号报告和备注。呼号会自动变成大写，主控呼号会留下来，方便连续记。

设备、天线、呼号和 QTH 会从词库里联想。输入新内容时，词库会收下这条，以后可以再搜到。功率和高度不进这四类词库，但可以随「一键复用数据库信息」从以往记录里填回来。

记错上一条时可以撤销。已经在表里的记录可以再编辑或删除。点名台上能看到总记录数、今日记录和最近 7 天记录。

## 会话怎么管

在会话页：

- **新建会话**即可开始。记录留在本机。
- **继续记录**回到还在进行的会话。
- 本地会话用 **结束记录**。记录还在，之后可以恢复。这不需要服务器。
- 历史可以按「全部 / 我的记录 / 共同记录 / 已结束」筛选。没有协作副本时不会出现「共同记录」。退出登录后，已经下载过的协作副本仍能在历史里找到。
- 「已结束」只是本机上的分类，不会因此变成公开归档。

这几件事不要混：

- 换页面、换会话、暂时断网，都不是离开协作。
- 协作的发起人要结束这场，到「协作与成员」里 **结束共同记录**。同步确认后，成员都不能再改；记录和成员关系还在。
- 参与者 **离开协作** 只退出自己。本机已有记录变成只读，其他人不受影响。以后要重新邀请或申请。
- 共同记录不能当成普通本地会话去点「结束记录」。
- **另存独立会话**（在更多操作里）只复制已经保存的表格记录，并切到一个新的本地会话。原来的协作、待同步队列和草稿都还在，不会自动退出。

恢复一个已结束的本地会话不会结束其他会话。

## 数据

数据页有这些分页：

- **记录与导出**：把当前会话导出成 JSON、Excel 或 ADIF，也可以从 JSON、Excel 导入到当前会话。导出路径留空时用系统下载目录。账户如果同步了 Excel 样式，导出会按那套抬头和文件名来。
- **查询词库**：管理设备、天线、呼号、QTH。可以搜，也可以导入、导出词库 JSON。
- **本地数据库**：导出或导入整库备份，也可以清空本机库。导入前会先给出备份里的会话数、记录数和词条数。这是本机文件，不是服务器上的备份。
- **同步冲突**：只有登录并开启个人云之后，两边改了同一处才会出现。没有冲突时不必进。

词库里的内置条目和你自己加的条目不是一回事。云同步只上传你添加的词条，以及你删掉内置词条的记录，不会把整份内置词库再传一遍。

可选的文字助手可以从本机历史里提出「词库里缺了什么、要不要改名或合并」。它只给建议，确认之前不改词库，也不改已经记过的记录。

## 设置里值得知道的

- **外观**：主题色、亮色或暗色。界面缩放（80%–150%）只存在这台设备上。
- **工作台**：和当前记录界面有关的布局。
- **主控屏**：给主控看的显示。桌面端可以开独立窗口。
- **AI 辅助**：默认关闭。语音识别和文字助手各自配置，音频直接发给你填的服务，不经过协作服务器。结果只是候选，不会自动保存，也不会自动填时间和主控呼号。配语音接口见 [AI 语音识别配置指南](ai-speech-recognition.md)。
- **服务器与账户**：只有要用云同步、好友或共享时才需要。可以把服务器的 `/connect`、`/client/` 或门户链接直接粘进去，客户端会取出服务器地址。链接里没有密码。手机、macOS 和网页可以扫描服务器连接页的二维码；Linux 和 Windows 改为从图片识别。识别到地址后会先确认，确认后才检查服务器，不会登录。
- **应用**：关于、许可和诊断信息。

「呼号历史一键复用」在工作台设置里。打开后，呼号栏可以根据本机以往记录填设备、天线、QTH、功率和高度。它不新增一条词库下拉。

## 接上自己的服务器

服务器是另一套程序。没装服务器时，上面的本地记录、词库、历史和导入导出都照常。

登录在「设置 → 服务器与账户」。公网或真实账号请用 HTTPS。Android 允许连接局域网里的 `http://` 自建服务器，那只适合你信任的网络。

登录之后可以单独用下面的能力，不必全部打开。

### 个人云同步

服务器声明了个人云和个人词库快照时，登录后会双向同步你自己的会话、点名记录和词库改动。这些记录不会写进协作会话，也不会出现在服务器的协作会话列表里。

两台设备各改了不同的地方，能自动合并。同一字段两边都改了，才要你选。从云端换下来的记录不会改本机设置，也不会动协作会话。

整库导入或清空之后，会先停住自动覆盖，等你确认新的同步基线。共享之前如果云端还没配对好，客户端会要求先处理同步，不会偷偷覆盖云端。

### 好友与协作

服务器支持好友协作时，会话页有「好友与协作」，里面是好友、消息、会话。

- 按用户名加好友，对方接受后才成立。
- 会话所有者可以邀请好友，并选「可编辑」或「仅查看」。对方接受后会下载并打开这场协作。
- 会话默认私有。所有者打开好友发现后，好友只能看到标题并申请加入，获批后才能看记录。
- 消息里可以接受、拒绝或取消。好友可以删除、拉黑或解除拉黑。已经在场内的成员权限，仍到这场的成员管理里改。
- 支持账号通知的服务器会即时推送好友请求、邀请和申请。断线重连会补一次最新列表。旧服务器没有这个通道时，大约每 30 秒刷新一次，也可以手动刷新。
- 未登录时不会建立这条连接。

协作记录的增删改会排队同步。断线、重启之后用原来的操作补上，不会无故记成两条。只读成员、已被移出的人，以及服务器上已经关闭的会话，都不能再改。

真正冲突的那一条，在你选择「用远端」或「保留本地再试」之前不能继续编辑。

### 账号会话共享

这是把**你账号里已经有的会话**授权给同一个服务器上的另一个用户，不是邀请对方加入一场实时协作，也不会把对方变成好友。

在客户端的共享里可以：

- **持续共享全部**：包含现在和以后新建的本人会话。新的本地会话要先完成云同步，对方才看得到。
- **多选会话**：只共享勾上的会话，以后新建的不会自动算进去。
- **仅查看**，或 **允许新增、修改记录**。删除记录要另外打开，而且必须同时允许修改。
- 删除整个会话、结束会话、再转授给别人，始终只有所有者能做。已结束的会话只能查看。

对方在「历史会话 → 共享」里看。接受邀请不会把你当前正在记的会话切走。

**共享词库**是这项授权上的一个开关，默认在新开授权时打开。以前已经发出、当时还没有这个开关的授权保持关闭，需要的话再打开。服务器太旧、没有这项能力时，客户端不会显示也不会发送这个开关。

打开之后，对方只能在这些共享会话里：

- 用你的设备、天线、QTH 做联想。你自己的同名词条优先。呼号栏不会因此多出一份词库下拉。
- 在被允许修改记录时，按呼号用「一键复用数据库信息」填入设备、天线、QTH、功率和高度。只读共享不能借这个按钮改记录。

对方改不了你的词库。这些内容也不会写进对方的词库或数据库。关掉开关或撤销授权后，对方就用不了。撤销共享不影响对方已经单独加入的协作。

### 公开页面

公开 Live Share 和公开归档都要所有者主动发布。

- Live Share 是进行中或已结束会话的只读公开页，链接带有单独的密钥。它不是成员登录。
- 公开归档是已关闭会话的静态页面，不跟着现场改。

## 本机数据在哪

桌面和手机的数据库是应用支持目录里的 `openlogtool_rust.db`。不要在软件开着的时候直接改这个文件。要备份或换机器，用「数据 → 本地数据库」导出备份，再在另一台导入。

Web 版的数据按网站来源（协议、域名、端口）分开存放。清除这个网站的数据，本地记录会一起没。除本机外，Web 版需要 HTTPS。

日志在应用支持目录的 `app.log`。程序崩溃时，Windows、Linux、macOS 的系统或应用崩溃报告位置见仓库 README 的「崩溃诊断」。那一节是给排错的，正常记点名用不到。

## 安装时会碰到的两件事

- Windows 便携包要整包解压再运行，不能只拷一个 exe。安装版会带上同一套运行库。
- macOS 第一次打开未签名的应用时，系统会提示开发者未验证。另外，已发布的 3.0.3-R 在部分 Mac 上会一启动就被系统杀掉；这是已知问题，要等带修复的新安装包。设置里暂时没有开关可以绕过。
